# Precision Brass Craft — Website

## Struktur Folder
```
precision-brass-craft/
├── index.html              → Homepage
├── css/
│   └── style.css           → Semua styles
├── js/
│   └── main.js             → Interaktivitas (cursor, animasi, form)
└── pages/
    ├── hot-stamping.html   → Halaman layanan Hot Stamping
    ├── embossing.html      → Halaman layanan Embossing & Debossing
    └── kontak.html         → Halaman kontak + FAQ
```

## Cara Membuka
Buka `index.html` di browser. Tidak perlu server untuk menjalankan website ini.

## Fitur
- Custom cursor kuningan
- Scroll reveal animations
- Magnetic CTA button
- Animated counter numbers
- Portofolio masonry grid
- FAQ accordion
- File upload drag & drop
- Fully responsive (mobile/tablet/desktop)
